商業簡介網站｜#13 線上報名進階

本版以 #12 線上報名系統 v1 為基礎，加入：
- 報名截止時間
- 報名人數上限
- 管理員審核（待審核／已通過／未通過）
- 會員報名、取消、重新申請時的通知
- 管理員審核結果通知
- 自訂報名欄位
- 後台報名名單 CSV 匯出
- 資料庫 trigger 伺服器端檢查截止與名額，避免只靠前端限制

使用：
1. 保留原本可用的 config.js。
2. 將 schema_upgrade_rerunnable.sql 在 Supabase SQL Editor 執行一次。
3. 執行後若 PostgREST 未立即更新，可執行： notify pgrst, 'reload schema';
4. 再部署網站檔案。

既有 #12 報名資料會保留。新活動可在後台設定進階報名規則。
